# B1_P01-11 — Sunni six-book numbered-hadith verification evidence (v1.1)

Date: 2026-10-03 · Phase 3 of the v1.2 work package · Status: **PRINT BLOCKED stays** · Generated only from `tools/verify_sunni.py` output / the corpus it reads; no memory-based identification is used as evidence.

## 1. Method

1. From `audit/B1_P01-11_UNIDENTIFIED_REFERENCES_AUDIT_v1.2.csv` (328 rows) every number attached to Bukhari / Muslim / Abu Dawud / Tirmidhi / Ibn Majah / Nasa'i in the **Text** and **Candidate_Source** columns was extracted (Bengali digits converted), including numbers proposed by the audit as corrections. Three further numbers were taken from `Audit_Note` (Abu Dawud 1641, REF-005) and are tagged `AU`. Numbers surfaced by this verification's own corpus search (Bukhari 520, Muslim 1794.01) are tagged `NEW`. Origin tags in the Verdict column: `MS` = number written in the ledger Text; `AU` = only audit-proposed; `NEW` = found by this search.
2. For every (book, number) `python3 tools/verify_sunni.py show <book> <number>` was run (outputs kept in the scratchpad). Because `show` prints only 230 characters, the full Arabic text was read through the same corpus (`verify_sunni.find`) and the decisive phrase was asserted verbatim (script aborts if a quoted phrase is not in the text).
3. Each (book, number, row) was compared with the **exact manuscript sentence/claim** quoted in the ledger Text and classified: EXACT_MATCH, PARTIAL_MATCH, WRONG_NUMBER, WRONG_TEXT, WRONG_SUBJECT, GRADING_MISMATCH, SOURCE_EXISTS_BUT_CLAIM_TOO_STRONG, NOT_FOUND, EDITION_DEPENDENT.
   * GRADING_MISMATCH is used when the text matches but the majority of printed graders give a weak-type grade (Daif / Very Daif / Munkar) **and** the ledger line carries no grade qualifier, or when the ledger attributes a grade to the wrong grader (Abu Dawud 2972).
   * SOURCE_EXISTS_BUT_CLAIM_TOO_STRONG: no (book, number, row) needed it in this pass (the ledger lines are source-notes, not flat prose claims); the label is kept in the vocabulary only.
4. Wording searches (`search "<Arabic substring>"`) were run for every term in the task and some additions; the CLI prints at most 6 hits, so hit lists were additionally enumerated through the corpus module.

## 2. Corpus

* `tools/_hadith-api/editions/ara-{bukhari,muslim,abudawud,tirmidhi,ibnmajah,nasai}.json` (fawazahmed0/hadith-api Arabic editions, already present; nothing re-fetched). Bukhari/Abu Dawud/Tirmidhi/Ibn Majah/Nasa'i = standard (sunnah.com-style) numbering; Muslim is matched on `arabicnumber` = Abd al-Baqi numbering with sub-ids (`2408.01` …).
* **Grades are not the compilers'.** The `grades` field prints later scholars/editors only: Al-Albani, Ahmad Muhammad Shakir, Shuaib Al Arnaut, Zubair Ali Zai, Bashar Awad Maarouf, Muhammad Muhyi al-Din Abdul Hamid (Abu Dawud), Muhammad Fouad Abd al-Baqi (Ibn Majah), Abu Ghuddah (Nasa'i). Bukhari and Muslim entries carry **no** grade field. Grades below are reproduced exactly as printed; none is upgraded or downgraded here.
* **Tirmidhi's own hukm:** the structured grade field has none ("compiler grade: not in corpus"). However the corpus **text** field of Tirmidhi entries often embeds Tirmidhi's own remark (e.g. 3723 «هذا حديث غريب منكر», 3868/3874 «حسن غريب», 3819 «حسن صحيح»). These are quoted in the Grading column as "remark embedded in text field". This is a deviation from the brief's blanket formula "compiler grade: not in corpus" — flagged because it changes the picture (3868/3874: Tirmidhi «حسن غريب» vs Al-Albani/Shakir «Munkar»).

## 3. Numbering caveats

1. **`show muslim N` tool bug (fixed during this pass).** Until the coordinator's fix, `verify_sunni.find()` matched Abd al-Baqi numbers only when they had no sub-suffix; for ids such as `2408.01` it silently fell back to the corpus-internal sequential `hadithnumber` and printed a **different hadith** (empty "Introduction" entries for 8 and 91). My first pass saw this (e.g. `show muslim 2408` printed a Zakat hadith) and verified every Muslim line against the sub-id (`N.xx`) directly. After the fix **every Muslim number was re-run** (`show muslim <n>` for 8, 91, 395, 667, 705, 761, 863, 1015, 1637, 1759, 1821, 1822, 1851, 1905, 1907, 2175, 2266, 2369, 2404, 2408, 2424, 2449, 2450, 2581, 2800-2802, 2816-2818, 2888, 2989, 6062): the fixed tool returns the `N.xx` sub-reports that are cited below, so no classification or grading note changed; `show muslim 6062` now prints NOT FOUND. **Muslim numbers were re-verified after the tool fix**; each Muslim line says so in the Edition-note column. Non-Muslim books were never affected.
2. **Bengali-edition numbers** (not standard numbering): REF-049 Bukhari «1815» (standard 1815 = Ka'b b. Ujra, lice; the hadith is standard 1954); REF-075 Bukhari «2874, 3446, 6270, 496» (standard numbers print unrelated hadith); REF-107 Muslim «6062 / p. 917» (no AB 6062; corpus-internal id 6062 = AB 2336.01, unrelated); REF-126 Bukhari 4240 «Bengali-edition number to map». None can be mapped without the author's edition — **PAGE-CHECK**.
3. REF-223 Tirmidhi «2950/2951 সংস্করণভেদে»: in corpus numbering «اتقوا الحديث عني … برأيه» = 2951 and «من قال في القرآن بغير علم» = 2950.
4. Corpus `section` labels are not fully reliable (e.g. Tirmidhi 3723 prints «Chapters on Tafsir», Muslim 2800 prints «Characteristics of the Day of Judgment…»); they are quoted only as a PAGE-CHECK hint.

## 4. Findings that change the v1.2 ledger (read first)

* REF-075: the audit's «3110 = وهي جويرية فأقبلت تسعى» is **wrong**; the phrase is Bukhari 520 (and Muslim 1794.01 in a different wording). Bukhari 3110 is the Miswar / Abu Jahl's-daughter report.
* REF-087: Muslim 91 does **not** contain «مثقال حبة من خردل من كبر» (AB 91.01/.03 «ذرة من كبر»; 91.02 «حبة خردل من كبرياء»). Verbatim: Abu Dawud 4091, Tirmidhi 1998, Ibn Majah 59 and 4173.
* REF-013/201: Abu Dawud 5023 reads «فسيراني في اليقظة», not «فقد رآني»; exact «فقد رآني» = Bukhari 110, Muslim 2266.01 (also Tirmidhi 2276, Ibn Majah 3900-3905).
* REF-039: Muslim 2175.01 **does** contain «يجري من الإنسان مجرى الدم»; the «يبلغ مبلغ الدم» variant is 2175.02 (and Bukhari 2035/3101). Neither has «من ابن آدم» (only Bukhari 7171).
* REF-054: corpus Bukhari 2010 reads «نعم البدعة هذه»; ms quotes «نعمت».
* REF-134: «حسبنا كتاب الله» is in Bukhari 114, 4432, 5669, 7366 and Muslim 1637.03 — **not** in Bukhari 4431/3053 or Muslim 1637.01.
* REF-317: Muslim 2989.01 does contain «أقتاب» (ledger note "not surfaced" superseded).
* REF-016: audit pointer «Tirmidhi 3370 = الدعاء هو العبادة (Nu'man b. Bashir)» is wrong; 3370 is Abu Hurayra. «الدعاء هو العبادة» = Tirmidhi 2969, 3247, 3372; Abu Dawud 1479; Ibn Majah 3828.
* REF-073: Tirmidhi 3868 and 3874 — Al-Albani **and** Shakir print Munkar, while Tirmidhi's own text remark is «حسن غريب»: the ledger line carries no grade.
* REF-079/2972: Abu Dawud's own «قال أبو داود» in 2972 is not a grade; graders are Al-Albani, Muhyi al-Din Abd al-Hamid, Zubair.
* REF-276: Bukhari 784 says «صلى مع علي رضى الله عنه **بالبصرة**» — Basra, not Kufa.
* REF-131: Bukhari 4240 contains night burial by Ali and «ولم يؤذن بها أبا بكر»; it contains no washing/shrouding and no will by Fatima to conceal the grave.
