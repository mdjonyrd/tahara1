## Critical bugs found

### BUG-01 — Abu Dawud 2972 grading is misattributed
The manuscript currently says the 2972 report is `আবু দাউদের মতে «ضعيف»`. The current Sunnah.com record displays the grading as **Da'if (Al-Albani)**, not as Abu Dawud's own grading. Revise the source note to attribute the grading to al-Albani, or omit the grading until the intended printed edition is checked.

### BUG-02 — Umm Ayman / Aus ibn al-Hadathan is still unresolved in the manuscript
Page 217's source block explicitly leaves the Umm Ayman testimony, Ali testimony, Kitab Sulaym, al-Ihtijaj, and Aus ibn al-Hadathan unresolved. The prose on page 213 nevertheless presents the testimony as settled fact. The research layer has now separated these claims: Baladhuri has a Sunni report of Ali + Umm Ayman testimony; Shia sources have further versions; Aus ibn al-Hadathan belongs to a different counter-testimony chain in the Shia material, not simply “Umm Ayman's witness.” Do not merge these recensions.

### BUG-03 — `উম্মে আইমান জান্নাতি` is overstated
The manuscript says Rasulullah ﷺ declared Umm Ayman a woman of Paradise. Ibn Sa'd has the wording, but the located report is **mursal** and has been graded weak in later hadith criticism. Therefore the prose should not present it as an unqualified sahih hadith. Use source-attributed wording such as “ইবনে সা‘দের একটি মুরসাল বর্ণনায়…” unless a stronger primary chain is separately established.

### BUG-04 — Muslim 2408 wording must not be merged with Tirmidhi 3786/3788
Muslim 2408 contains the Thaqalayn / Book of Allah + Ahl al-Bayt wording. Tirmidhi 3786 has the exact `كتاب الله وعترتي أهل بيتي` wording; Tirmidhi 3788 has the `وعترتي أهل بيتي` wording plus the Hawd clause. The manuscript already partially recognizes this distinction, but every later occurrence must use the same rule.

### BUG-05 — “Fatima leader of women” reference should be normalized
Bukhari 3624 does contain the statement within the Aisha narration, while Bukhari 3767 is the direct chapter/reference presentation for `فاطمة سيدة نساء أهل الجنة`. This is not a factual error, but the reference should be normalized consistently according to the exact wording being quoted.

### BUG-06 — “dies without knowing his Imam” must not be equated with Muslim 1851
Muslim 1851a says `من مات وليس في عنقه بيعة مات ميتة جاهلية` — death without a pledge of allegiance. It is not the same wording as `من مات لا يعرف إمامه مات ميتة جاهلية`, which belongs to Shia source material such as al-Kafi. The manuscript correctly notes this distinction in one place; lock that distinction globally.

### BUG-07 — local Windows path in a citation is not publication-safe
One source note contains a local path beginning `F:\HZ Fatima Zahra...`. This is machine-local and cannot serve as a portable citation. Replace it with the Library/source-file identifier, a stable URL, or a proper source register ID.

### BUG-08 — S-174 remains an open research lock
`S-174` is used for the claim that Satan cannot take the Prophet's ﷺ form, but the source note says source verification is still open. This must not be treated as a completed citation. The claim has primary Sunni parallels (e.g. Muslim 2266a; Bukhari related wording), but the exact source chosen for the manuscript must be locked.

### BUG-09 — one source section contains internal source-text cleanup language
Several source notes say things like “খাতার কয়েকটি মুদ্রণ-ত্রুটি এখানে ঠিক করে লেখা — ছাপার আগে মূল কিতাবে মেলাতে হবে.” That is an audit note, not a publication citation. Keep it in the audit ledger, not in the final book's visible source apparatus.

### BUG-10 — source status vocabulary is being mixed inside prose
`বর্ণিত আছে`, `PAGE-CHECK`, and `CONFIRMED` occur both as internal audit statuses and as manuscript-adjacent wording. Before final publication, these must be separated into: (a) reader-facing attribution and (b) internal QA status.
